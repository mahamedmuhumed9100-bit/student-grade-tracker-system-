# Student Grade Tracker (Python)

A simple **command-line Python program** to help students enter their subjects and grades, and then view a summary of their performance.

**Author:** Mahamed Muhumed  
**GitHub:** https://github.com/mahamedmuhumed9100-bit

## Features

- Add multiple subjects and grades
- Validates that grades are between 0 and 100
- Calculates:
  - Average grade
  - Highest grade
  - Lowest grade
- Gives a basic performance label:
  - Distinction (>= 70)
  - Merit (>= 60)
  - Pass (>= 50)
  - Below pass

## Technologies Used

- Python 3 (no external libraries required)

## How to Run

1. Make sure you have **Python 3** installed.
2. Open a terminal in this folder.
3. Run:

```bash
python grade_tracker.py
```

4. Enter subjects and grades when prompted.
